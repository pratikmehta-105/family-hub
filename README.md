# FamilyHub V1
Mobile-first family emergency and life management PWA.

## GitHub Pages
Upload all files to the repository root. Then go to Settings → Pages → Deploy from a branch → main → /(root) → Save.

## V1
Includes emergency contacts, family profiles, notes, contacts, medicines, documents, reminders, custom family fields, and JSON import/export.

Data is stored in this browser only. Do not store highly sensitive information until secure authentication and cloud storage are added.
